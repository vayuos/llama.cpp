================================================================================
                        TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: Server won't start
Fix:     pkill -f llama-server
         sleep 2
         ./FULL_BENCHMARK.sh

Problem: Low throughput (< 450 tok/sec)
Fix:     1. Check GPU layers: grep "offloaded" server_logs_benchmark_*.txt
         2. Check embeddings: grep "ROCm0 model buffer" server_logs_benchmark_*.txt
         3. If embeddings on CPU (low number), rebuild with fix

Problem: OOM errors
Fix:     Edit FULL_BENCHMARK.sh:
         Change: -c 8192 → -c 4096
         Change: -b 4096 → -b 2048
         Then run again

Problem: GPU errors
Fix:     Check ROCm: rocm-smi
         Try env var: export GGML_HIP_PINNED_MEM=1
         Then run: ./FULL_BENCHMARK.sh
