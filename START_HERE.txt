================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Build takes forever
SOLUTION: Normal - takes 20-30 minutes. Cannot be shortened.

PROBLEM: Build fails with errors
SOLUTION: Check output for compiler errors, install missing dependencies

PROBLEM: Binary not found after build
SOLUTION: Build failed. Check error messages and retry

PROBLEM: Benchmark shows low throughput (< 450 tok/sec)
SOLUTION:
  1. Check if all 49 layers are on GPU
  2. Check if token embeddings are on GPU (not CPU)
  3. Review BENCHMARK_GUIDE.md

PROBLEM: GPU out of memory (OOM)
SOLUTION:
  1. Edit FULL_BENCHMARK.sh
  2. Change: -c 8192 → -c 4096
  3. Change: -b 4096 → -b 2048
  4. Re-run benchmark

PROBLEM: Server crashes during benchmark
SOLUTION:
  1. Check logs: grep -i "error\|crash\|oom" server_logs_benchmark_*.txt
  2. Review GPU environment variables
  3. Try: export GGML_HIP_PINNED_MEM=1 && ./FULL_BENCHMARK.sh
