   (or download from https://developer.nvidia.com/cuda-downloads)

2. Clean and rebuild:
   cd /home/viren/llama/llama.cpp
   rm -rf build
   mkdir build && cd build

   cmake .. \
       -DCMAKE_BUILD_TYPE=Release \
       -DGGML_CUDA=ON \
       -DLLAMA_BUILD_TOOLS=ON

   make -j$(nproc)

EXPECTED RESULT: Full GPU build with all tool executables linked

================================================================================
TROUBLESHOOTING
================================================================================

Q: Build fails saying "nvcc not found" or "CUDA not found"
A: CUDA toolkit not installed. Run:
   sudo apt install nvidia-cuda-toolkit

   Then rebuild.

Q: Build takes very long or runs out of memory
A: Reduce parallel jobs:
   make -j2
   instead of make -j$(nproc)

Q: Tools still won't link
A: Use CPU-only build (Option A) to verify code compiles
   Then debug CUDA installation separately

Q: Can I use CPU build for production?
A: Yes! Your code will work on CPU, just slower (~50-100x for generation)
   Use GPU build if speed is critical
